# Ansible Demo Collection

This folder contains beginner-friendly Ansible examples for common topics.

## Topics covered

- Error handling
- Filters and lookups
- Plugins
- Roles
- Templates and handlers
- Vault

Each example is written with simple comments so it is easier to understand the idea behind the Ansible feature.

## How to run

From this folder, you can run a playbook like this:

```bash
ansible-playbook ErrorHandling/error_handling_demo.yml
```

> Replace the demo target host as needed for your environment.
